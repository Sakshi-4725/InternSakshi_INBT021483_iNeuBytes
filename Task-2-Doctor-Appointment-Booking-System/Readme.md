# 🩺 Doctor Appointment Booking System

A modern, responsive Doctor Appointment Booking System built using **HTML5**, **CSS3**, and **JavaScript (ES6)**. This project allows users to browse doctors, search and filter doctors by department, view doctor profiles, and book appointments through an interactive and user-friendly interface.

▶️ How to Run the Project
💻 Run Locally
Download or clone the repository.
Open the project folder in Visual Studio Code.
Install the Live Server extension.
Open index.html.
Right-click and select Open with Live Server.

The project will open in your browser.



The project can be deployed using Vercel or GitHub Pages.
